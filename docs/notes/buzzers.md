# 有源蜂鸣器与无源蜂鸣器

同一份“输出高电平，等 80 ms，再输出低电平”的程序，接一种蜂鸣器会“嘀”一声，换另一种却只在开关瞬间轻轻“嗒”一下。把定时器从 1 kHz 改成 2 kHz，有的器件音调变了，有的只是发出断续的杂音。

先别怪 PWM。你可能把“控制内部振荡器的电源”与“直接让发声元件振动”混成了一件事。[4.1](/lessons/4-1) 假定使用有源蜂鸣器，[5.3](/lessons/5-3) 演奏音调则需要合适的无源蜂鸣器。两节不是两种写法任选，而是器件前提不同。

## 先读型号，而不是只看有没有“+”

在本课程的习惯叫法中：

- **有源蜂鸣器**对应内置振荡/驱动的 indicator。施加规格允许的直流电源后，它自己产生发声所需的周期激励，通常音调固定；MCU 只负责什么时候响、什么时候停。
- **无源蜂鸣器**对应需要外部激励的 transducer。你提供交变或周期驱动，音调主要由激励频率决定，响度还与频响、驱动电压和安装有关。

“有源”不是说需要电源而“无源”不要电；两者发声都需要能量。正极标记只帮助识别极性，不能单独证明内部有振荡器。三脚模块的 S 引脚也可能是高有效或低有效，板上还可能已有晶体管和电阻，不能只凭外壳黑圆帽判断。

查器件规格时，至少记下额定/允许电压、工作电流、驱动波形、频率或谐振频率、极性、SPL 测试距离和安装方式。没有型号的器件，不建议直接连到 GPIO 上用“看看响不响”来辨认。

## 有源/无源与磁性/压电是两套分类

磁性发声器通过线圈磁场推动振膜，等效负载包含电阻与电感。压电发声器利用材料受电场形变发声，电气上更接近电容性负载。

这与是否内置振荡器是两个维度：有磁性有源、磁性无源，也有压电有源、压电无源。因此“无源就是压电”“蜂鸣器都是线圈，所以一律跨一个二极管”都不成立。Same Sky 原厂的分类把 indicator/transducer 和 magnetic/piezo 分开说明，选驱动时也必须分开判断。

磁性无源器件持续接直流可能只在开始时机械移动，随后主要发热；不要长时间用直流测试。压电片也不是普通电阻，单边开关释放以后需要合适的电荷回路。是否适合单极方波、是否要求交流或桥式驱动，以具体器件手册为准。

## 跟做一：让已知的有源蜂鸣器短鸣

使用规格已确认、带兼容驱动输入的板载有源蜂鸣器电路，沿用 4.1 的对象。GPIO 驱动的是控制端，不承担蜂鸣器全部电流。先确认控制端高有效还是低有效，并在初始化前后都保持关闭。

给定输入是“每次确认按键按下，启动一次 80 ms 短鸣”。预期是保持一段约 80 ms 的使能电平，期间蜂鸣器内部自行振荡；用示波器看控制引脚，应看到一个宽脉冲，而不是音频方波。扬声器内部振荡的频率不一定能在这个控制端看到。

不用阻塞延时：记录开始时刻，主循环每圈用无符号时间差判断是否到期。重新触发时要规定语义，本例采用**从这次触发重新计 80 ms**，不是排队，也不是把全部脉冲宽度累加。时基按毫秒计时且轮询及时的前提下，即使起点接近 32 位回绕，差值比较仍成立；主循环长时间阻塞时，关闭动作会延迟。

若模块低有效，就把“响/静”的电平转换集中在驱动层，业务层仍说“响 80 ms”。不要在不同调用处临时交换 SET/RESET，否则启动时和超时关闭时很容易漏改。

## 跟做二：让合适的无源蜂鸣器改变音调

这次换成**明确允许下述周期驱动**的无源发声器和匹配的外部驱动级。沿用主线已经配置的 TIM3_CH1，不把元件直接挂到没有校核电流的 MCU 引脚上；确认该通道没有同时驱动 LED 或其他负载。

假设计数器时钟已经是 1 MHz，边沿对齐向上计数、PWM mode 1、有效高，输出驱动也为高电平导通。停止输出时应让驱动级确实关闭。先在不接负载时用示波器检查控制波形：

| 目标 | ARR | CCR1 | 预期控制波形 |
|---|---|---|---|
| 静音 | 499 | 0 | 持续低电平 |
| 2 kHz | 499 | 250 | 周期 500 µs，高 250 µs |
| 1 kHz | 999 | 500 | 周期 1 ms，高 500 µs |
| 约 440 Hz | 2271 | 1136 | 周期 2272 µs，约 440.14 Hz |

表中假设计数时钟已确定，不是把 MCU 主频直接拿来除。若 TIM3 输入为 84 MHz，则 PSC=83 才得到 1 MHz；实际工程要查时钟树。频率是计数时钟/(ARR+1)，本模式下占空比是 CCR/(ARR+1)。这些公式不直接适用于中心对齐模式。

电压、周期和默认关闭状态核对无误，再断电接入已匹配的驱动与发声器。短时间切换 1 kHz 与 2 kHz，预期音高改变；实际响度不必相同，因为器件在谐振附近通常更有效。440 Hz 只是展示计算，若器件规定的有效工作频段不包括它，不必强行播放，更不能为“听不见”继续升高电压。

运行中改频率时要同时更新 ARR 和 CCR，否则 ARR 变小后，原 CCR 可能大于新 ARR，输出变成持续有效电平。开启 ARR/CCR 预装载可让新值在更新事件装入，但**CPU 的两次写入不自动成为同一事务**；更新事件若夹在它们之间，仍可能出现一个不匹配周期。最简单的教学办法是先静音、在停止状态配置并按外设要求产生更新事件，再启用；无缝变调应设计同步更新流程。

## 驱动级把控制与负载电流分开

一种常见的磁性无源器件驱动是低侧 N 沟道 MOSFET：

~~~text
负载电源 +V ── 磁性蜂鸣器 ── MOSFET 漏极 D
                                   源极 S ── GND
MCU 控制 ── 栅极串联电阻 ── 栅极 G
                               │
                            下拉电阻
                               │
                              GND
~~~

MCU 与负载电源需要兼容的公共参考地。MOSFET 必须在实际栅极高电平下有足够的导通保证，不能只看 VGS(th)；关断耐压、负载峰值电流、功耗也要校核。栅极下拉让 MCU 复位高阻时保持关断；栅极串联电阻用于约束充放电与边沿，数值需要结合器件和频率选择。裸 BJT 方案则需要基极限流，不能把基极当不耗电的逻辑输入。

对于上述**磁性线圈、单端低侧开关**，常见保护是跨线圈的反向续流二极管：阴极接 +V，阳极接漏极侧。正常导通时二极管反偏，关断时给线圈电流提供路径；选型需满足电流、反压与恢复要求。它会影响退磁速度和声音，某些设计采用其他钳位方式，不能脱离器件推荐电路只看“有没有二极管”。

压电器件不是这套感性负载。单端压电驱动可能需要复位电阻，桥式驱动则通过两端互补电压工作；随便跨二极管可能钳掉正常波形。若桥式驱动两端都在变化，普通接地示波器不能把地夹夹到其中一端，应使用额定合适的差分测量方案。

## 为什么有源蜂鸣器接 PWM 也会“变声音”

有源蜂鸣器被低频开关供电，会发出一串断续提示音；开关更快时，内部振荡器启动、供电纹波和包络互相作用，也可能改变听感。但这不等于像无源器件那样可靠地由 PWM 频率设置音符。主线需要“固定音短鸣”用有源最方便，需要“音阶”则选择适合频段与驱动的无源器件。

也不要把占空比当线性的音量旋钮。磁路、压电频响、耳朵响应和驱动限制都会影响结果。需要规范音量时，应按声压级测试条件测量，不能根据“桌上听起来差不多”声称达到报警要求。

## 练习：改频率后为什么突然不响了

计数时钟 1 MHz，原来 ARR=999、CCR=500。现在只把 ARR 改成 249，CCR 保持 500，仍为有效高 PWM mode 1。请预测波形与风险；若要变成 4 kHz、50%，应如何改？

<details>
<summary>展开答案</summary>

计数器从 0 数到 249，始终小于 500，参考输出持续有效，控制波形成为直流高。无源发声器不再得到预期音频激励，磁性负载还可能持续通电发热。4 kHz 需要 250 个计数，ARR=249、CCR=125；按安全更新顺序同时准备两者，并确保停音时驱动关闭。不要把 CCR 设置成 ARR，当作精确 100% 或 50%。

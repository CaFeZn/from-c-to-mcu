# 用内部参考电压校准ADC

同一个约 1.5 V 的稳定信号，接在两块板上，程序一块显示 1.50 V，另一块显示 1.62 V。程序都写着“参考电压 3300 mV”，但万用表量到第二块板的实际 ADC 参考电压接近 3.0 V。

ADC 给出的是输入相对参考的比例。**把尺子的实际长度 3.0 V 写成 3.3 V，所有换算结果都会被放大约 10%。** 多采几次取平均，不会纠正这把写错长度的尺子。

本篇延伸 [8.2 ADC 采集电压](/lessons/8-2)。具体对象是 STM32F407 的 ADC1、12 位右对齐；“校准”主要指利用内部参考修正参考电压估计，不是自动消除整个 ADC 和模拟前端的全部误差。

## 先做一个不用改变板子供电的计算实验

设某一颗芯片在工厂参考电压 3300 mV 时，内部参考通道的校准码为 1500。现在同一通道读到 1650；外部信号通道读到 2048。

先猜：内部参考码变大，是参考电压变大还是变小？

<details>
<summary>展开推导</summary>

内部参考电压近似不变；量同一个电压所占的格数变多，说明整把尺子的总长变小。采用比值计算：实际参考电压 ≈ 3300 × 1500 ÷ 1650 = 3000 mV。

外部信号按主线的端点比例换算，约为 2048 × 3000 ÷ 4095 = 1500.37 mV，四舍五入显示 1500 mV。若仍乘 3300，显示会是 1650 mV。1500 和 1650 是本题给定的模拟输入，不是每颗 F407 都应该读出的固定值。

</details>

这组输入和预期输出已由独立 C99 测试实际验证。不要为了复现数字，把外部稳压源和开发板 USB 电源直接并接；计算实验已经足够检验公式。真实供电调整必须先确认板上电源路径和额定条件。

## VREFINT 是被测对象，不是把 VREF+ 切换成了 1.21 V

F407 的内部参考电压 VREFINT 接到 ADC1_IN17。通过内部通道读取它时，ADC 的转换参考仍是 VREF+ 与 VREF−，并没有自动改成 VREFINT。

DS8626 Rev 12 表 72 给出的 VREFINT 典型值是 1.21 V，所列温度条件下范围为 1.18～1.24 V。直接假定每颗都是精确的 1210 mV，最多只能得到粗估值。想减少芯片间差异，应使用具体芯片的校准码。

还要分清三个名字：

- **VDDA：** 模拟部分的电源。
- **VREF+：** ADC 正参考端；有些封装/板子把它接到 VDDA，有些可使用独立参考。
- **VREFINT：** 芯片内部相对稳定、可以经 ADC1 测量的电压。

因此比值公式首先估计的是 ADC 的实际参考电压。只有确认 VREF+ 与 VDDA 相连时，才可把结果称为 VDDA。表读得再准，也不能替代查看原理图。

## F407 的校准常量，要按已核对的资料使用

本篇读取并核对的 **DS8626 Rev 12（2026 年 3 月）§6.3.24 表 73**，为 STM32F405xx/F407xx 列出了内部参考校准数据：

| 项目 | 本篇采用的依据 |
|---|---|
| 数据手册符号 | VREFIN_CAL |
| 校准条件 | 30 °C，VDDA = 3.3 V |
| 地址范围 | 0x1FFF7A2A～0x1FFF7A2B，16 位数据 |
| 官方 LL 名称 | VREFINT_CAL_ADDR、VREFINT_CAL_VREF |

固定版本 ST LL 头文件也给出了相同地址和 3300 mV 条件。不要把另一系列芯片的 3000 mV 校准电压、分辨率或地址照搬过来，也不要仅因旧文章说法不同，就断言所有 F407 都没有这项数据。

在**已确认型号与资料适配的 F407 板级工程**中，可以使用官方 LL 定义读取：

```c
#include "stm32f4xx_ll_adc.h"

/* 仅用于目标芯片；不可在 PC 程序中解引用此地址。 */
static uint16_t read_factory_vref_code(void)
{
    return *VREFINT_CAL_ADDR;
}
```

在初始化函数中调用它，并把返回码与 `VREFINT_CAL_VREF` 一起交给后面的计算函数。这是目标端数据获取片段，不是 PC 测试代码。应检查读数不是 0、全 1 或超出 12 位合理范围；换芯片、旧批次或资料不匹配时重新核对适用性，不能把“地址能读出一个数”当作有效校准的充分条件。若不能确认工厂值，可用精密万用表测得的本板参考电压和同条件下 VREFINT 平均码，建立自己的单点校准记录，明确记录温度、分辨率和采样设置。

## 先把内部通道读正确

可以先只读 VREFINT，验证稳定后再和外部通道组合。沿用主线单次轮询的启动、等待、取值、停止流程，配置如下：

1. 只用 ADC1，选择内部 VREFINT 通道，也就是通道 17。它不是让你去接某根“17 号引脚”；ADC2/ADC3 不能代替这里的 ADC1。
2. 12 位、右对齐、单次转换，先不混入扫描、注入组和循环 DMA。
3. 开启公共控制寄存器的 TSVREFE。所核对的 HAL 在配置 ADC1 的 VREFINT 通道时会设这个位；使用寄存器或 LL 时自己保证开启。
4. 开启内部通道后留足启动时间。表 72 给出的启动时间最大值是 10 µs。入门实验可在非中断初始化流程中等待 1 ms；不要把空循环次数随便称作精确微秒，也不要以为每个 HAL 版本都替 VREFINT 单独等好了。
5. 采样时间必须单独满足要求。表 72 给出 VREFINT 的最小采样时间 10 µs；21 MHz 下 144 周期只有约 6.86 µs，不够。选择 480 周期，约为 22.86 µs；总转换时间还要加 12 周期。

启动等待和采样窗口不能互相抵消：即使启动后等了一秒，每次只给 3 个周期采样仍可能错误。保持内部通道开启后，不必每个样本都重复等待 1 ms。

得到稳定的参考码后，可在 ADC 停止时切回 PA1，按主线读取外部信号；供电变化慢时，两次相邻测量可以组成一对。更连续的做法是用规则扫描的两个 Rank 配合 DMA，固定存储顺序如“外部通道、VREFINT”，并让每个通道有各自的采样时间。它们仍是先后采样，不是严格同时；快速电源扰动下的比值补偿有时效限制。

## 把除零和无效值挡在公式外

令 Ccal 为校准时的参考通道码，Cnow 为现在的码，Vcal 为校准时的参考电压：

> VREF+估计值 = Vcal × Ccal ÷ Cnow

比值中分辨率因子抵消的前提是两次码使用同样的分辨率和对齐。把 10 位测量码直接除以 12 位校准码，或把左对齐原始寄存器值直接代入，都会得到错误结果。

下面是完整的 C99 计算函数；它不访问硬件，输入可以来自工厂值，也可以来自自己的板级单点校准：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

static bool vref_from_cal(uint16_t calibration, uint16_t measured,
                          uint32_t calibration_mv, uint32_t *reference_mv)
{
    if (reference_mv == NULL || calibration == 0u || calibration >= 4095u ||
        measured == 0u || measured >= 4095u ||
        calibration_mv < 1800u || calibration_mv > 3600u) {
        return false;
    }
    uint64_t numerator = (uint64_t)calibration * calibration_mv;
    uint32_t result = (uint32_t)((numerator + measured / 2u) / measured);
    if (result < 1800u || result > 3600u) {
        return false;
    }
    *reference_mv = result;
    return true;
}
```

先乘后除避免提前截断，加半个分母做整数四舍五入，64 位中间量避免扩大算法范围时轻易溢出。函数拒绝参考通道饱和、零码、明显不合理的校准值；失败时不改输出，调用者必须检查返回值，不能把旧结果当新结果。

1800～3600 mV 是这份示例的合理性筛查范围，不是对所有条件的工作许可。比如本篇 ADC 时钟为 21 MHz，仍应满足数据手册中相应供电区间的限制；估计到低供电后，不能仅因函数返回 true 就继续按原时钟使用。

## 它能修正什么，不能修正什么

最直接的收益是修正“把实际参考电压硬写成 3300”的比例误差，并利用单颗芯片校准减少 VREFINT 个体差异。以下问题仍在：

- VREFINT 自身有温漂，工厂校准不是任何温度下的完美真值。
- 外部电阻分压比、输入漏电、源阻抗、通道建立时间、ADC 偏移与非线性不会被全部抵消。输入已经饱和时，更不能用公式恢复超过量程的电压。
- 若电位器两端接的是同一 VDDA，参考电压下降时滑动端的真实电压也下降。此时原始码可能基本不变，换算后的绝对电压下降反而是正确结果。验证“同一电压是否稳定”应使用独立且安全的稳定信号，而非这种比率式输入。
- 对参考码求平均可降低随机波动，但窗口太长会跟不上供电变化；应把校准结果的时间戳与外部样本配对，别用几秒前的参考值解释一次瞬时测量。

## 练习：读到了更大的参考码

工厂码仍为 1500，当前 VREFINT 码变为 1600。参考电压约是多少？若当前码是 0，能否把分母改成 1 以保证程序不停？

<details>
<summary>展开答案</summary>

3300 × 1500 ÷ 1600 = 3093.75 mV，四舍五入为 3094 mV。当前码为 0 时应返回错误并排查通道、使能、启动等待、采样窗口和搬运位置。把 0 改成 1 只会制造约 4.95 千伏的荒谬结果，掩盖真正故障。必要时保留上次可信值并标记“陈旧”，但不能伪装成此次成功测量。

</details>

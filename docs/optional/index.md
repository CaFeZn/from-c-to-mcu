# 第 0 章 工具与构建：自学选读

> **这一章不是入门前置，可以整章跳过。** 第一次学 C，直接从 [[1.0_搭建环境]] 开始，然后进入 [[1.1_Hello_World]]。不会解释编译器和链接器，不妨碍先写程序。
> 回到 [[00_教程导览]]

这里收纳的是工具内部的原理。主线仍会说明“这个工具有什么用、现在为什么需要、怎样操作”，不是把工具当成黑盒；只有预处理细节、目标文件、符号和链接机制等深入内容放到这里。需要时选读，不必按目录顺序补课。

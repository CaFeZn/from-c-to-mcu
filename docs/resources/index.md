# 参考视频映射：补充资料与拓展入口

> **定位**：这些视频是本教程的补充资料。有些主题在主线里只讲到应用所需的深度，想继续深入、再看一个案例，或换一种讲法理解时，可以从这里选看。
> **不要求课前看完，也不作为进入下一节的条件。** 不看视频，仍然可以沿主线学习和完成练习。
> 来源：[B 站《RoboMaster电控教程》](https://www.bilibili.com/video/BV1z14y1G77V)，UP：TrojanGeneric。合集的本地索引共 88 集，其中 87 集有自动转写字幕。
> 合集序号与视频自己的【x.y】编号不同；下表使用本地合集的 01–88 序号。本教程仍用 1.0、2.2 等章节编号。
> 原视频由原作者发布；本站仅提供主题映射，不转载第三方字幕。

## 一、按需要补，不按顺序补课

主线负责让读者把当前的事情做出来；分支笔记和外部视频一起提供进一步学习的入口。本教程不必把每个主题都讲到最深，也不需要假定自己的讲解一定比参考视频更深入。

- 已经理解并能完成当前练习，就继续主线，不额外增加观看任务。
- 还有一个点没理解，按主题找到对应集，再看相关内容。
- 对某个方向有兴趣，进入拓展视频，不要求把整套合集看完。
- 视频里涉及不同的开发板、IDE、库版本或接口时，先辨认差异。本教程的环境仍是 VS Code + CMake，单片机主线使用 CubeMX + HAL。

下面是基于现有合集标题与本地索引整理的**主题关联**，不是对每集深度或覆盖范围的逐段评测。具体段落与时间戳，正式引用时再核对，不凭标题补写不存在的内容。

## 四、放到具体小节时怎么写

各节的“想深入？”末尾可以加一个可选的外部资料入口。不要只放整套合集，最好同时写清**对应集数、主题，以及它能补充的那一点**。例如：

> [!abstract] 补充资料 · 按需选看
> 想再看一份 CAN 通信的讲解，可以看《RoboMaster电控教程》第 13 集【3.2】CAN 通信。把它作为本章的另一种讲解和案例来源，不要求先看完。视频与本教程的开发板、版本和代码组织可能不同。
> 入口：[[D_参考视频映射#二、与主线相关的补充资料]]

只有在确实核对过原视频或字幕片段后，才增加精确时间戳，或写“这一段专门解释了某个细节”。自动转写字幕只帮助定位，不能代替原视频、器件手册和实际验证。

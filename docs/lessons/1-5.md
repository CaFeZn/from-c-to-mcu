## 先看一个怪现象

你给快递员一张纸条，上面写着"幸福里 12 号"，请他把那里的包裹全取回来。他到了门口，回头问你：那里有几个包裹？

纸条上没写。他要么只取一个就走，要么一直取下去，取到别人家里去。

C 语言把一个数组交给函数，递过去的就是这样一张纸条。先看一段代码：

```c
#include <stdio.h>

/* 参数写成 int a[10]，看起来像是"收一个 10 个元素的数组" */
void f(int a[10]) {
    printf("in f   : sizeof(a) = %lu\n", (unsigned long)sizeof(a));
}

int main(void) {
    int a[10] = {0};
    printf("in main: sizeof(a) = %lu\n", (unsigned long)sizeof(a));
    f(a);
    return 0;
}
```

> [!question] 先猜一猜
> 在 `main` 里，`a` 是 10 个 `int`，每个 `int` 占 4 字节，所以第一行是 40。
> 那 `f` 里这一行打印什么？
> A. 40　B. 10　C. 一个比 40 小得多的数　D. 编译不过
> 先选一个，再往下翻。

> [!success]- 揭晓
> 我这台机器上的输出：
>
> ```
> in main: sizeof(a) = 40
> in f   : sizeof(a) = 4
> ```
>
> 选 C。`f` 里量到的是 4，不是 40，也不是 10。而且构建时 gcc 已经提醒过你了：
>
> ```
> src/array_decay.c: In function 'f':
> src/array_decay.c:5:63: warning: 'sizeof' on array function parameter 'a' will return size of 'int *' [-Wsizeof-array-argument]
>      printf("in f   : sizeof(a) = %lu\n", (unsigned long)sizeof(a));
>                                                                ^
> src/array_decay.c:4:12: note: declared here
>  void f(int a[10]) {
>             ^
> ```
>
> 4 是我这台机器上"一个地址"的大小。在 64 位系统上通常是 8。

## 动手做

### 第一步：数组基本功

数组就是一排连号的房子：同样大小的房间，挨着排，从 0 号开始编号。先把它跑起来：

```c
#include <stdio.h>

int main(void) {
    int a[5] = {10, 20, 30, 40, 50};   /* 5 个 int，挨着排在一起 */

    /* 整个数组的字节数 ÷ 一个元素的字节数 = 元素个数 */
    size_t n = sizeof(a) / sizeof(a[0]);
    printf("sizeof(a)    = %lu\n", (unsigned long)sizeof(a));
    printf("sizeof(a[0]) = %lu\n", (unsigned long)sizeof(a[0]));
    printf("n            = %lu\n", (unsigned long)n);

    int sum = 0;
    for (size_t i = 0; i < n; i++) {   /* 下标从 0 到 n-1，没有 a[n] */
        printf("a[%lu] = %d\n", (unsigned long)i, a[i]);
        sum += a[i];
    }
    printf("sum = %d\n", sum);
    return 0;
}
```

保存为 `src/array_basic.c`，在 `c-lab` 的 `CMakeLists.txt` 末尾加一行 `add_demo(array_basic)`，然后配置、构建、运行：

```

cmake --build build               # 构建
./build/array_basic               # 运行（Windows 命令提示符里写 build\array_basic.exe）
```

本节后面的例子跑法都一样，只写文件名。

你应该看到：

```

sizeof(a[0]) = 4
n            = 5
a[0] = 10
a[1] = 20
a[2] = 30
a[3] = 40
a[4] = 50
sum = 150
```

有两点要记住。第一，下标从 0 开始，5 个元素的下标是 0 到 4，**没有** `a[5]`。第二，元素个数用 `sizeof(a) / sizeof(a[0])` 算：整排房子占多少字节，除以一间房占多少字节。

### 第二步：抓出那张"纸条"

回到开头的怪事。f 里为什么变成了 4？我们不直接告诉你，用三个猜想一个个检验。

先把开头那段程序跑起来：保存为 `src/array_decay.c`，加一行 `add_demo(array_decay)`，构建并运行。构建时 gcc 会给出上面揭晓里的那条警告，先放着。

> [!failure] 猜想 1：`f` 拿到的是 `a` 的副本，整个数组被复印了一份
> 如果是副本，`f` 里量出来应该还是 40。实际是 4。对不上。划掉。

> [!failure] 猜想 2：`f` 里的 `sizeof` 是按参数声明里写的 `[10]` 在算
> 如果是这样，把 `[10]` 改成 `[1000]`，结果应该跟着变。我们来检验。划不划掉，看下面的程序。

下面这段把方括号里的数字改成了 1000，同时让 `f` 打印地址，并在里面改 `a[0]`：

```c
#include <stdio.h>

/* 探针：把方括号里的数字改成 1000，并在函数里改 a[0] */
void f(int a[1000]) {
    printf("in f   : sizeof(a) = %lu, sizeof(int *) = %lu\n",
           (unsigned long)sizeof(a), (unsigned long)sizeof(int *));
    printf("in f   : a = %p\n", (void *)a);
    a[0] = 777;
}

int main(void) {
    int a[10] = {0};
    printf("in main: sizeof(a) = %lu\n", (unsigned long)sizeof(a));
    printf("in main: a = %p\n", (void *)a);
    f(a);
    printf("in main: a[0] = %d (after f)\n", a[0]);
    return 0;
}
```

保存为 `src/array_decay_probe.c`，在 `CMakeLists.txt` 末尾加一行 `add_demo(array_decay_probe)`，构建并运行。

```
in main: sizeof(a) = 40
in main: a = 0061fef8
in f   : sizeof(a) = 4, sizeof(int *) = 4
in f   : a = 0061fef8
in main: a[0] = 777 (after f)
```

先看 `sizeof(a)`：还是 4，和方括号里写几没关系。猜想 2 划掉。**方括号里的数字，函数根本没看。**

> [!success] 猜想 3：`f` 拿到的不是数组，而是一个地址
> 三个现象一起支持它：
> - `f` 里的 `a` 和 `main` 里的 `a` 是**同一个地址**
> - `f` 里改 `a[0]`，回到 `main` 变成了 777。副本不会这样
> - `f` 里 `sizeof(a)` 等于 `sizeof(int *)`，都是 4
>
> 猜想 3 活下来了。

现在可以给它一个名字了。数组名在大多数场合会被当成"第 0 个元素的地址"，数组传进函数时尤其如此，这个现象叫**[[【原理】数组退化与指针算术|数组退化]]**。参数里写 `int a[10]`，编译器实际按 `int *a` 处理。这里的 `int *`，就是下一步要认识的东西：**指针**。

### 第三步：指针就是那张纸条

纸条上写的是门牌号，也就是**地址**。拿着纸条，你可以去看房子里有什么，也可以去改。两个符号就够了：

- `&x`：取 `x` 的地址，"这间房子的门牌号是多少"
- `*p`：顺着 `p` 这张纸条找到房子，看里面的东西

```c
#include <stdio.h>

int main(void) {
    int x = 7;
    int *p = &x;                 /* p 是一张纸条，上面写着 x 的地址 */

    printf("x = %d, &x = %p\n", x, (void *)&x);
    printf("p = %p, *p = %d\n", (void *)p, *p);

    *p = 8;                      /* 顺着纸条找到房子，改里面的东西 */
    printf("after *p = 8: x = %d\n", x);
    printf("sizeof(p) = %lu, sizeof(x) = %lu\n",
           (unsigned long)sizeof(p), (unsigned long)sizeof(x));

    int a[4] = {10, 20, 30, 40};
    int *q = a;                  /* 数组名可以直接当纸条用 */
    for (int i = 0; i < 4; i++) {
        printf("q + %d = %p, *(q + %d) = %d, a[%d] = %d\n",
               i, (void *)(q + i), i, *(q + i), i, a[i]);
    }
    printf("q + 1 is %lu bytes after q\n",
           (unsigned long)((char *)(q + 1) - (char *)q));
    return 0;
}
```

保存为 `src/pointer_basic.c`，在 `CMakeLists.txt` 末尾加一行 `add_demo(pointer_basic)`，构建并运行。

```
x = 7, &x = 0061ff10
p = 0061ff10, *p = 7
after *p = 8: x = 8
sizeof(p) = 4, sizeof(x) = 4
q + 0 = 0061ff00, *(q + 0) = 10, a[0] = 10
q + 1 = 0061ff04, *(q + 1) = 20, a[1] = 20
q + 2 = 0061ff08, *(q + 2) = 30, a[2] = 30
q + 3 = 0061ff0c, *(q + 3) = 40, a[3] = 40

```

> [!example] 我这台机器上的结果（Windows，MinGW gcc 6.3.0；地址每台机器、每次运行都可能不同）
> 注意四点：
> - `p` 和 `&x` 是同一个数。`*p = 8` 之后，`x` 真的变成了 8
> - `sizeof(p)` 是 4，和 `x` 一样大，**与房子有多大没关系**，纸条上只写门牌号
> - `q + 1` 的地址比 `q` 大 4，正好是一个 `int` 的大小。指针加一，是"走到下一间房子"，不是"加一个字节"
> - `*(q + i)` 和 `a[i]` 打印出来一样。`a[i]` 其实就是 `*(a + i)` 的另一种写法

### 第四步：用纸条交换两个变量

1.4 里你已经发现，函数的参数是复印件，所以函数改不到外面的变量。现在有了纸条，就有办法了。

> [!question] 先猜一猜
> 下面的 `swap_bad` 和 `swap`，哪个能真正交换 `x` 和 `y`？运行后各打印什么？

```c
#include <stdio.h>

/* 错误版：交换的是两张复印件 */
void swap_bad(int a, int b) {
    int t = a;
    a = b;
    b = t;
}

/* 正确版：拿着两张"纸条"，顺着地址去交换原件 */
void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

int main(void) {
    int x = 1, y = 2;

    swap_bad(x, y);
    printf("after swap_bad: x = %d, y = %d\n", x, y);

    swap(&x, &y);
    printf("after swap    : x = %d, y = %d\n", x, y);
    return 0;
}
```

保存为 `src/swap.c`，在 `CMakeLists.txt` 末尾加一行 `add_demo(swap)`，构建并运行。先猜，再运行。

> [!success]- 揭晓
> 输出：
>
> ```
> after swap_bad: x = 1, y = 2
> after swap    : x = 2, y = 1
> ```
>
> `swap_bad` 交换的是两张复印件，原件没动。`swap` 收到的是两张纸条，顺着地址去交换原件，所以有效。注意调用时要写 `swap(&x, &y)`，把门牌号递进去。

这就是 C 里"让函数改外面的变量"的标准做法：**传地址**。

### 第五步：传数组，必须带长度

回到快递员的问题。纸条上没写有几个包裹，那就**当面告诉他**。所以处理数组的函数，一定要多一个参数：长度。

```c
#include <stdio.h>

/* 只读不写的函数，用 const 承诺"我不会改你的数据"；长度 n 必须另外传 */
int sum(const int *a, size_t n) {
    int s = 0;
    for (size_t i = 0; i < n; i++) {
        s += a[i];
    }
    return s;
}

/* 把前 n 个元素都设成 v */
void fill(int *a, size_t n, int v) {
    for (size_t i = 0; i < n; i++) {
        a[i] = v;
    }
}

/* 打印数组：每个处理数组的函数，都要带着 (a, n) 一起走 */
void print_array(const char *title, const int *a, size_t n) {
    printf("%s:", title);
    for (size_t i = 0; i < n; i++) {
        printf(" %d", a[i]);
    }
    printf("\n");
}

int main(void) {
    int a[5] = {1, 2, 3, 4, 5};
    size_t n = sizeof(a) / sizeof(a[0]);   /* 在数组所在的地方算长度 */

    print_array("before", a, n);
    printf("sum = %d\n", sum(a, n));

    fill(a, n, 7);
    print_array("after ", a, n);
    printf("sum = %d\n", sum(a, n));
    return 0;
}
```

保存为 `src/array_len.c`，在 `CMakeLists.txt` 末尾加一行 `add_demo(array_len)`，构建并运行。

```
before: 1 2 3 4 5
sum = 15
after : 7 7 7 7 7
sum = 35
```

几个细节：

- `n` 是在 `main` 里算出来的，因为只有在数组定义的地方，`sizeof(a)` 才是整排房子的大小。进了函数，这条路就走不通了。
- `sum` 的参数前面加了 `const`，意思是"我只看不改"。调用者一看就知道数据是安全的，编译器也会拦住你手滑写出的赋值。
- 长度用 `size_t` 这种无符号类型，和 1.3 里的坑呼应：别用 `int n` 去和 `size_t` 比较，会触发有符号无符号比较的警告。

再留意一件事：`sum`、`fill`、`print_array`，每个处理数组的函数，参数里都有一对 `(a, n)`，总是一起出现。现在只有一个数组，还不觉得什么。如果同时有三个数组呢，比如名字、读数、阈值，每个函数就得带着六个参数。先把这个烦恼记下来，1.6 会回来解决它。

### 第六步：字符串是以 \0 结尾的数组

C 里没有"字符串"这种独立的类型。字符串就是 `char` 数组，最后多一个值为 0 的字节，写作 `'\0'`，表示"到此为止"。

> [!question] 先猜一猜
> `char s[] = "abc";` 之后，`sizeof(s)` 是几？`strlen(s)` 是几？

> [!success]- 揭晓
> `sizeof(s)` 是 4，`strlen(s)` 是 3。可见的 3 个字符，再加末尾自动补上的 `'\0'`。`strlen` 数的是"到 `'\0'` 之前有几个"，不算它。

下面的程序把每个字节打出来，然后做一个破坏实验：

```c
#include <stdio.h>
#include <string.h>

/* 自己实现 strlen：从头走，走到 '\0' 为止，数走了几步 */
size_t my_strlen(const char *p) {
    size_t n = 0;
    while (*p != '\0') {
        p++;
        n++;
    }
    return n;
}

int main(void) {
    char s[] = "abc";            /* 编译器自动在末尾补一个 '\0' */

    printf("sizeof(s) = %lu, strlen(s) = %lu\n",
           (unsigned long)sizeof(s), (unsigned long)strlen(s));
    for (size_t i = 0; i < sizeof(s); i++) {
        printf("s[%lu] = %d\n", (unsigned long)i, s[i]);
    }

    /* 探针：把中间一个字节改成 0，看字符串变成什么 */
    s[1] = '\0';
    printf("after s[1] = 0: \"%s\", my_strlen = %lu, sizeof = %lu\n",
           s, (unsigned long)my_strlen(s), (unsigned long)sizeof(s));

    /* 往小盒子里装大字符串：snprintf 会按容量截断，并保证末尾有 '\0' */
    char buf[8];
    snprintf(buf, sizeof(buf), "%s", "hello world");
    printf("buf = \"%s\"\n", buf);
    return 0;
}
```

保存为 `src/string_basic.c`，在 `CMakeLists.txt` 末尾加一行 `add_demo(string_basic)`，构建并运行。

```
sizeof(s) = 4, strlen(s) = 3
s[0] = 97
s[1] = 98
s[2] = 99
s[3] = 0
after s[1] = 0: "a", my_strlen = 1, sizeof = 4
buf = "hello w"
```

读输出：

- `s[3] = 0` 证明末尾真的有个 0
- 把 `s[1]` 改成 0 以后，`printf("%s")` 只打出 `a`，`my_strlen` 也只数到 1。所有处理字符串的函数，只认 `'\0'`，不管数组本来多大。`sizeof` 却还是 4，因为数组本身没变
- `buf` 只有 8 字节，`hello world` 装不下，`snprintf` 在第 7 个字符处截断，并保证末尾有 `'\0'`，所以是 `hello w`

**探针**：把 `buf` 改成 `char buf[4]`，先预测输出，再验证。

> [!success]- 揭晓
> 输出 `buf = "hel"`。4 字节里，3 个放字符，最后 1 个留给 `'\0'`。

### 第七步：没有人拦你（越界）

最后一道题。数组有 3 个元素，假如却把长度写成 8，会发生什么？先辨认非法访问，不要把错误程序的某次输出当成规则。

> [!question] 先猜一猜
> `sum(a, 8)` 会报错、崩溃，还是给出某个数？

```c
#include <stdio.h>

int sum(const int *a, size_t n) {
    int s = 0;
    for (size_t i = 0; i < n; i++) {
        s += a[i];
    }
    return s;
}

int main(void) {
    int a[3] = {1, 2, 3};

    printf("sum(a, 3) = %d\n", sum(a, 3));   /* 长度对：1+2+3 */

    /* 以下是不要执行的反例：sum(a, 8)、读取a[3]或写入a[3]，都超出了边界。 */
    return 0;
}
```

保存为 `src/array_oob.c`，在 `CMakeLists.txt` 末尾加一行 `add_demo(array_oob)`，只运行上面的合法版本，输出应为 `sum(a, 3) = 6`。`sum` 的前提不只有长度真实：每一步部分和也必须能用 `int` 表示，本例的 1、3、6 满足这个条件。

> [!success]- 揭晓
> `sum(a, 8)` 会访问不存在的数组元素，属于未定义行为：可能有诊断、可能崩溃、可能看似返回某个数，也可能因优化出现别的结果。C 不要求在每次下标访问时自动检查，所以“能编译”不证明边界正确；反过来也不能保证编译器一定不报警。

**读越界和写越界都不是合法的内存探测办法**。写越界还可能破坏其他数据，症状出现在很远的地方；没有立刻崩溃不是安全证据。应在访问前核对容量与索引，继续看[缓冲区溢出与边界检查](/notes/buffer-bounds)中的安全替代。

还有一种相关的错：返回一个局部变量的地址。

```c
#include <stdio.h>

/* 错误示范：返回局部变量的地址 */
int *bad(void) {
    int x = 5;
    return &x;
}

int main(void) {
    /* 不调用bad、不读取失效指针：这里只保留定义用于编译诊断。 */
    return 0;
}
```

将其保存为 `src/dangling_ptr.c`，只做编译诊断：`gcc -std=c99 -Wall -Wextra -fsyntax-only src/dangling_ptr.c`。不要添加解引用再运行；`-Werror` 等选项还可能把警告提升为错误。

构建时，gcc 会警告：

```
src/dangling_ptr.c: In function 'bad':
src/dangling_ptr.c:6:12: warning: function returns address of local variable [-Wreturn-local-addr]
     return &x;
            ^~
```

回想 1.4：函数返回后，自动对象 `x` 的寿命已结束，复制它的地址不能续命，之后不能用该指针访问它。按值返回，或把调用者提供的有效对象地址传给函数，才是这里需要的改法。详见[野指针与悬空指针](/notes/pointer-lifetime)。

## 刚才发生了什么

整理一下，这一节你撞上的其实是同一件事：

- **数组**是一排连号的房子，连续放在内存里
- **指针**是一张写着门牌号的纸条，大小只取决于地址有多长，与房子大小无关
- 数组交给函数时，递过去的是纸条（数组退化为指针），纸条上没有长度，所以长度要另传
- 字符串是以 `'\0'` 结尾的 `char` 数组，库函数靠这个 0 判断结束
- C 不检查下标，也不检查纸条指向的房子还在不在

回头看开头那道题：`f` 里量到的 4，量的是**纸条**，不是**整排房子**。现在你不用猜就能答了，而且知道该怎么补救：把长度另外传进去。

**到单片机上会怎样**：指针不只能指向你定义的变量，也能指向外设的寄存器，对着一个固定地址读写，就是在控制硬件（后面章节会遇到，原理见 [[【原理】寄存器与内存映射|寄存器与内存映射]]）。另外，单片机上通常没有操作系统替你看着，越界写入往往不会当场崩溃，而是悄悄改坏另一个变量。所以"数组传参带长度、下标不越界"在板上更要当成铁律。

## 记住这几条

1. **数组传进函数，长度必须另外传**（`size_t n`）。在函数里对数组参数用 `sizeof`，量到的是指针的大小。
2. **长度在数组定义的地方算**：`sizeof(a) / sizeof(a[0])`，不要在函数里算。
3. **只读不写的指针参数加 `const`**。
4. **想让函数改外面的变量，传它的地址**（`swap(&x, &y)`）。
5. **字符串末尾有 `'\0'`，容量要比可见字符多一格**。往字符数组里写东西，用 `snprintf` 这类带容量的函数，不要用不检查长度的 `strcpy`。
6. **下标范围是 0 到 n-1**，循环条件写 `i < n`。越界没有人报错。
7. **不返回局部变量的地址**。指针定义时就赋值，暂时没有指向就赋 `NULL`，用之前判断。

3. 先写下预测，再运行。下面程序打印什么？（预测）

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char s[] = "hello";
    char *p = s;

    printf("%lu %lu\n", (unsigned long)sizeof(s), (unsigned long)strlen(s));
    p += 2;
    printf("%c\n", *p);
```

> [!success]- 提示与答案方向
> 1. `main` 里是 80（10 个 8 字节的 `double`），`f` 里还是 4（我这台机器上指针的大小）。房子变大了，纸条没变。
> 2. 参考答案（保存为 `src/array_reverse.c`，加一行 `add_demo(array_reverse)`），运行结果是 `max = 9` 和 `7 1 4 9 3`：
>
> ```c
> #include <stdio.h>
>
> /* 原地倒置：头尾两个下标往中间走，每次交换一对 */
> void reverse(int *a, size_t n) {
>     if (n < 2) {
>         return;
>     }
>     size_t i = 0;
>     size_t j = n - 1;
>     while (i < j) {
>         int t = a[i];
>         a[i] = a[j];
>         a[j] = t;
>         i++;
>         j--;
>     }
> }
>
> int max_of(const int *a, size_t n) {
>     int m = a[0];                /* 约定：n 至少为 1，调用者负责保证 */
>     for (size_t i = 1; i < n; i++) {
>         if (a[i] > m) {
>             m = a[i];
>         }
>     }
>     return m;
> }
>
> int main(void) {
>     int a[5] = {3, 9, 4, 1, 7};
>     size_t n = sizeof(a) / sizeof(a[0]);
>
>     printf("max = %d\n", max_of(a, n));
>     reverse(a, n);
>     for (size_t i = 0; i < n; i++) {
>         printf("%d ", a[i]);
>     }
>     printf("\n");
>     return 0;
> }
> ```
>
> 3. 输出依次是：
>
> ```
> 6 5
> l
> llo
> he
> 0
> ```
>
>    - `6 5`：`"hello"` 5 个字符加 `'\0'` 占 6 字节
>    - `p += 2` 之后 `p` 指向第三个字符，所以是 `l`，再按字符串打印是 `llo`
>    - `s[2] = '\0'` 把原数组在这里截断，`s` 变成 `he`
>    - `p` 指的恰好就是被改成 0 的那个字节，所以 `strlen(p)` 是 0

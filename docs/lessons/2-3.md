# 2.3 怎么读手册

> **这一节你会做出**：不靠搜索引擎，自己从手册里查出三件事：某个引脚能干什么、某个外设最高能跑多快、某个引脚最多能带多大电流；再学会从原理图里认出 LED 接在哪个引脚、该输出高还是低才会亮。
> **前置**：[[2.1_单片机里有什么]]、[[2.2_开发环境与第一次点灯]]　｜　**预计**：阅读 + 动手 50 分钟

> [!tip] 跳读自测：这一节你可能不用读
> 先回答下面四个问题（写下来，别只在心里答）。**全部答对**就直接跳到 [[2.4_程序是怎么跑起来的]]；有一题拿不准，就从头读。
> 1. 想知道 PA9 这个引脚除了串口还能当什么，去数据手册的哪一张表里查？
> 2. 同一个引脚，能不能同时当 USART1_TX 和 TIM1_CH2 用？
> 3. 下面是 LED 的接法。配上这行代码，灯是亮还是灭？
>
>    ```
>    3V3 ──[330Ω]──►|── PB13
>    ```
>
>    ```c
>    HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_SET);
>    ```
>
> 4. 数据手册里 Absolute maximum ratings（绝对最大额定值）表里的数，能当作"正常使用的条件"吗？
>
> > [!success]- 答案，以及跳过后要带走的东西
> > 1. Alternate function mapping（复用功能映射）表，行是引脚，列是 AF0 到 AF15。
> > 2. 不能。一个引脚在同一时刻只能选其中一个功能，这就叫引脚复用。
> > 3. 灭。LED 一端接 3V3，另一端接引脚：引脚输出低电平时，电流从 3V3 经电阻、LED 流进引脚，灯才亮。输出高电平（`SET`）时两端没有压差，灯灭。
> > 4. 不能。那是"超过就可能损坏"的极限，正常使用要落在 General operating conditions（一般工作条件）内，并留出余量。
> >
> > **带走清单**：本节没有代码和配置。要带走的是三个习惯：①查引脚功能看复用映射表；②查最高频率看参考手册的 RCC 章和数据手册的工作条件；③点灯之前先读原理图，确定灯是高电平亮还是低电平亮。

## 先看一个怪现象

没有人是把字典从头背到尾，才学会写作文的。手册也一样：你的任务不是读完，而是**查得到**。

同事递给你一块新板子，问："串口 1 的发送脚接在哪个引脚上？"你不用问任何人，也不用搜索引擎。三本手册加一张原理图，答案都在里面，只是你要知道"部首"在哪。这一节，就是教你查这本字典的部首。

本节的比喻就是**查字典**：目录和框图是部首检字表，表格是正文，脚注是容易被忽略的小字注解。

> [!question] 先猜一猜
> STM32 的 APB1 总线（挂着大部分低速外设）最高能跑多少 MHz？2.2 里我们让 CubeMX 把 APB1 分频设成了 /4，你觉得这个 /4 是随便选的，还是有来历？先想一个答案，第三步我们去手册里验证。

## 动手做

### 第一步：准备检索工具

- 把三本手册的 PDF 都打开，侧边栏打开 Bookmarks（书签）。书签就是目录，比翻页快得多。
- 用 `Ctrl+F` 搜**英文原词**，不要搜中文。英文原版是最新的，译本可能落后。
- 看到一个陌生外设，先读它那一章开头的 Introduction 和 Main features，再看框图。这两处通常能回答"它能不能干我要的事"。

### 第二步：案件一，这个引脚能干什么

打开**数据手册**，找到 Pinouts and pin description（引脚与引脚描述）这一章。里面有两张最常用的表：

- **引脚定义表**（Pin and ball definitions）：每个引脚一行，写着它的名字、类型、I/O 结构（后面第四步会用到）、复位后的默认功能。
- **Alternate function mapping（复用功能映射）**：行是引脚，列是 AF0 到 AF15，格子里是这个引脚在这个编号下能当的功能。

任务：找到 **PA9** 那一行，把格子里所有的功能抄下来。再反过来找：**USART1_TX 出现在哪些引脚上**。

> [!success]- 揭晓
> PA9 一行里，应该能看到 `USART1_TX` 和 `TIM1_CH2` 等功能（具体以你的手册为准）。反过来，`USART1_TX` 应该出现在 PA9 和 PB6 两处，对应的列是 AF7。本教程作者的一个 CubeMX 工程里，串口 1 就用的是 PA9 和 PB7，和这张表对得上。
>
> 重点是这个规律：**同一个引脚在同一时刻只能选一个功能。** 你在 CubeMX 里点一个引脚弹出的那个功能菜单，就是这张表里那一行的列表；选了 `USART1_TX`，它就不能同时当 `TIM1_CH2` 了。这叫引脚[[【原理】引脚复用机制|复用]]，4.2 会专门用它。

> [!example] 探针：对账
> 打开 CubeMX，点一下芯片图上的 PA9，看弹出菜单里有哪些功能，和你抄下来的那一行比一比。对得上，说明你读表的方法对了。

### 第三步：案件二，外设最高能跑多快

回到开头的问题：APB1 最高多少 MHz？这属于"外设怎么工作"，翻**参考手册**，找 RCC（Reset and clock control，复位与时钟控制）那一章，搜 `maximum allowed frequency`。

先别急着记数字，注意搜索结果。我手边这份 RM0090（Rev 21）里，这句话出现了**两次**，数字不同：

> [!success]- 揭晓
> - 第 6 章标题是 Reset and clock control for **STM32F42xxx and STM32F43xxx**：AHB 最高 180 MHz，APB2 最高 90 MHz，APB1 最高 45 MHz。
> - 第 7 章标题是 Reset and clock control for **STM32F405xx/07xx and STM32F415xx/17xx**：AHB 最高 **168 MHz**，APB2 最高 **84 MHz**，APB1 最高 **42 MHz**。
>
> 你用的是 F407，要看第 7 章。翻错章，数字就是错的。
>
> 所以先猜一猜的答案是：168 ÷ 4 = 42，刚好等于 APB1 的上限，这个 /4 是算出来的。同理 APB2 分频 /2 得到 84 MHz。这就是为什么 2.2 的时钟树是 168 / 42 / 84。

这里藏着一个读手册的大规律：**一本参考手册往往覆盖一整个系列的好几种型号。** RM0090 的书名里就列了 F405、F415、F407、F417、F427、F437、F429、F439。所以章节标题、表格列头、脚注里的"仅适用于 xxx"，一定要看。先确认你读的这一页，说的是不是你的型号。

### 第四步：案件三，电气限值

这类问题翻**数据手册**。找 Electrical characteristics（电气特性）一章，里面有三张表值得认识：

| 表 | 回答什么 | 怎么用 |
|---|---|---|
| Absolute maximum ratings（绝对最大额定值） | 超过就可能**损坏**的极限 | 设计时绝不能碰，更不是"可以这样用" |
| General operating conditions（一般工作条件） | 芯片**正常工作**的电压、频率、温度范围 | 你的设计要落在这个范围里 |
| I/O port characteristics（I/O 端口特性） | 引脚的输入电压阈值、输出能力 | 查引脚能不能直接带负载 |

任务：把下面三项查出来，填进你的笔记里。**本教程故意不给数字**：不同型号、不同版本的数字可能不同，而且这正是你该养成的习惯。

1. 一个 GPIO 引脚最多能灌入或输出多少电流
2. 整颗芯片所有引脚加起来的总电流上限
3. 能不能直接接 5 V 的信号

第 3 项要回到第二步的引脚定义表，看那个引脚的 **I/O structure** 一栏。标着 `FT` 的是五伏容忍（five-volt tolerant）引脚，但仍要读该表脚注与电气条件：模拟模式、内部上下拉、供电状态和输入电压范围可能限制这一能力，不能推导为所有模式或掉电时都安全。没有相应额定条件的引脚不能直接接 5 V；需要时采用[电平转换](/notes/voltage-tolerance)。

算一道应用题，把"查到的限值"用起来。假设 LED 的导通压降约 2.0 V（示例值，以你 LED 的规格为准），电源 3.3 V，串联 330 Ω：

```
I = (3.3 V − 2.0 V) ÷ 330 Ω ≈ 3.9 mA
```

把这个电流和你查到的单脚限值比一比，你就知道这盏灯是否安全，也知道电阻还能不能调小让它更亮。

### 第五步：读原理图，认出你的 LED

2.2 里你需要知道"LED 接在哪个引脚"。原理图能直接告诉你：

1. 在原理图里找到 LED 元件，顺着它的线看另一端。
2. 线会连到一个网络名（比如 `LED0`）。**同名网络名即使画在图的不同位置，也是连通的。**
3. 顺着网络名找到芯片的符号，看它接在哪个引脚上（比如 `PB13`）。
4. 看 LED 的另一端接的是电源还是地，判断极性。

LED 的接法常见两种：

```
灌电流（引脚输出低电平时亮）：

  3V3 ──[R]──►|── PB13        PB13 = 0，电流流进引脚，灯亮

拉电流（引脚输出高电平时亮）：

  PB13 ──[R]──►|── GND        PB13 = 1，电流从引脚流出，灯亮
```

符号 `►|` 就是 LED：三角形加一条竖线，竖线那一端是负极（电流从三角形的底边流向竖线）。

> [!example] 探针：读对了吗
> 读完你的原理图，先写下预测："我的灯是____电平亮。"再回到 2.2 的探针，用 `HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_SET)` 试一次。结果一致，说明你读对了。

## 刚才发生了什么

你一共做了三次"查字典"，每次都是同样的四个动作：**分类 → 选书 → 找部首 → 核对适用条件**。

| 想查什么 | 翻哪里 | 部首（先找这里） |
|---|---|---|
| 引脚能干什么 | 数据手册 | Alternate function mapping 表 |
| 外设最高频率 | 参考手册，兼看数据手册 | RCC 章（先确认型号）；Operating conditions 表 |
| 电气限值 | 数据手册 | Absolute maximum ratings、I/O port characteristics |
| 灯接在哪个引脚 | 原理图 | LED 元件，沿网络名找到芯片符号 |

还有一件事要说明。参考手册的每个外设章末尾，都有 Register description（寄存器描述），写着每个寄存器的地址偏移、复位值，以及每一位的名称和读写类型。现在你只需要知道它在那里；"为什么往一个地址写一个数就能让灯亮"，放在[[【原理】寄存器与内存映射|寄存器与内存映射]]里。

回到开头那本字典：你不需要背下 1757 页，你只需要知道三个部首在哪。

## 记住这几条

1. **先分类再翻书。** 引脚、电气、封装翻数据手册，外设怎么用翻参考手册，内核的事翻编程手册。
2. **查引脚功能看复用映射表。** 一个引脚同一时刻只能选一个功能。
3. **手册覆盖多个型号，先确认你读的这页适用于你的型号。** RM0090 里 F42x/F43x 和 F405/F407 的 RCC 章数字不同。
4. **F407 的最高频率：AHB 168 MHz，APB2 84 MHz，APB1 42 MHz。** 所以 CubeMX 里 APB1 分频是 /4，APB2 是 /2。
5. **绝对最大额定值不是工作条件。** 设计按 Operating conditions 来，并留出余量。
6. **接 5 V 器件之前，先查那个引脚是不是 `FT`。**
7. **点灯之前先读原理图，确定高电平亮还是低电平亮。** 不要靠试，更不要靠猜。
8. **手册说能、现象说不能，先查勘误表（Errata）。**

## 练习

1. 在你的板子原理图里找出 LED 和按键各接在哪个引脚，写下引脚名和极性。（复现）
2. 在复用映射表里列出 `USART1_RX` 的所有可选引脚。再看看其中有没有和你板子上其他用途冲突的。（改造）
3. 你想把一个 5 V 输出的串口模块的 TX，直接接到 PA10（USART1_RX）上。先不接，查表预测：可不可以？（预测）

> [!success]- 提示与答案方向
> 1. 按第五步的四步法，答案以你的原理图为准。
> 2. 答案以你的数据手册为准。`USART1_RX` 应该有 PA10 和 PB7 两处。
> 3. 取决于引脚定义表里 PA10 的 I/O structure 一栏是不是 `FT`。查到 `FT` 再看脚注里的条件；没标，就不能直连，要加电平转换或分压。

# 2.1 单片机里有什么

> **这一节你会做出**：认出一块板子上的关键件（芯片、晶振、复位键、调试口）；把型号 `STM32F407IGH6` 一段一段读出含义；知道遇到哪一类问题该翻哪一本手册。
> **前置**：第 1 章，至少读过 [[1.1_Hello_World]]　｜　**预计**：阅读 + 动手 40 分钟

> [!tip] 跳读自测：这一节你可能不用读
> 先回答下面四个问题（写下来，别只在心里答）。**全部答对**就直接跳到 [[2.2_开发环境与第一次点灯]]；有一题拿不准，就从头读。
> 1. 想知道 STM32F407 的某个引脚最多能输出多少电流，应该翻哪一本手册？
> 2. 想知道串口波特率寄存器每一位是什么意思，翻哪一本？想知道 PendSV 异常是什么，又翻哪一本？
> 3. 下面这行全局数组在电脑上没问题。放进 STM32F407 的工程里，编译链接会发生什么？
>
>    ```c
>    int g_table[100000];
>    ```
>
> 4. 单片机程序平时存在哪里？上电后，由谁把它装进内存运行？
>
> > [!success]- 答案，以及跳过后要带走的东西
> > 1. 数据手册（Datasheet）。电气参数在那里。参考手册只讲功能，它的前言里就写着电气特性请看数据手册。
> > 2. 前者翻参考手册（RM0090），后者翻内核编程手册（PM0214）。
> > 3. 链接失败。数组有 400,000 字节，整颗芯片的 RAM 一共才 192 KB，链接器会报 `.bss` 放不进 `RAM` 区。
> > 4. 存在 Flash 里。没有操作系统，也就没有人"装载"它：上电后 CPU 直接从 Flash 里取指令执行。
> >
> > **带走清单**：本节没有代码和配置。要带走的是：①两个数字，Flash 最大 1 MB、RAM 共 192 KB（后面设计数组和缓冲区时要算账）；②三本手册的名字和分工（数据手册、参考手册 RM0090、编程手册 PM0214），后面每一章都会让你去查。

## 先看一个怪现象

桌上放着一块板子，正中间一颗黑色方块。你想知道：它的一个引脚，最多能带动多大的电流？

你下载了最权威的那本手册，我手边这份参考手册 RM0090 有 1757 页（版本不同，页数略有出入）。从目录翻到附录，找不到。这不怪你，是翻错了本子：它的前言里自己就写了，电气特性请去数据手册找。

一颗芯片，三本手册，每本回答的问题不一样。这一节要做的事，就是把一块板子、一颗芯片、三本手册认全。

我们用一个比喻贯穿全程：**一座自给自足的小镇**。镇上有镇长、档案馆、办公桌、各种办事窗口，还有一条把它们连起来的马路。等下你会发现，这座小镇的每个角色，在芯片里都有对应的真名。

> [!question] 先猜一猜
> 你的电脑内存大概是 16 GB。STM32F407 这颗芯片里的 RAM（放变量的地方），你猜有多大？
> A. 几 MB　B. 一百多 KB　C. 几十 KB　D. 几个 GB
> 先选一个，第四步我们去手册里量。

## 动手做

### 第一步：认识一块板子

拿出你的开发板，对照下表，找到每一样并记下它的位置。不同板子长得不一样，找不到就翻板子自带的资料。

| 找什么 | 长什么样 | 它是干什么的 |
|---|---|---|
| 芯片 | 最大的方形黑块，上面印着 `STM32F407` 开头的型号 | 本节的主角 |
| 晶振 | 银色金属小块，或四脚小方块，旁边常有两个小电容 | 给芯片提供稳定的节拍 |
| 复位键 | 一个按钮，常标 `RST` 或 `RESET` | 按下，程序从头再来 |
| 调试口 | 一排针或座子，标 `SWD`、`SWCLK`、`SWDIO`，或者板载一个 USB 口 | 下载程序、调试都从这里走（2.2 用） |
| 电源部分 | 一颗稳压芯片，旁边有大电容 | 把输入电压变成芯片要的 3.3 V |
| LED 和按键 | 小灯、轻触开关 | 最简单的输出和输入（2.2 点灯） |

### 第二步：把型号读出来

芯片表面第一行通常是完整型号。以 `STM32F407IGH6` 为例，按段拆开：

| 段 | 含义 | 备注 |
|---|---|---|
| `STM32` | ST 公司基于 ARM Cortex-M 内核的 32 位微控制器 | |
| `F` | 通用型（general-purpose）产品线 | |
| `407` | 子系列。这一类里有 Cortex-M4 内核，最高 168 MHz | 内核和频率已在 RM0090 里核对 |
| `I` | 引脚数，对应 176 脚 | （待核对） |
| `G` | Flash 容量，1 MB | F407 的 Flash 最大 1 MB，本机示例工程链接脚本里 Flash 也是 1024 KB |
| `H` | 封装类型，UFBGA | （待核对） |
| `6` | 工作温度范围，约 −40 到 85 ℃ | （待核对） |

这张表里标"待核对"的几段，是我没有手边的数据手册可以逐字对照。你要养成的习惯正是这个：**型号怎么解码，以数据手册里 Ordering information（订货信息）一节为准**。

> [!example] 探针：解码你自己的板子
> 把你板子上芯片的丝印抄下来，按上面的表拆开。然后打开数据手册的 Ordering information，核对每一段。后缀不同，Flash 大小、引脚数、封装都不一样，写代码之前先确认你手上是哪一个。

### 第三步：请回三本手册

到 ST 官网你的芯片产品页的文档区，下载下面三本（都是 PDF，建议存在一个固定的文件夹里）：

| 手册 | 回答什么问题 | 本教程的用法 |
|---|---|---|
| 数据手册（Datasheet），F405 / F407 这一本，编号 DS8626（待核对） | 引脚怎么排、能不能接 5 V、电气参数、封装、型号 | 查引脚和电气限值（2.3） |
| 参考手册（Reference Manual），RM0090 | 每个外设怎么工作，寄存器地址和每一位的含义 | 查外设用法（贯穿后面各章） |
| 内核编程手册（Programming Manual），PM0214 | 指令集、中断和异常、内核自带的寄存器 | 查中断和内核行为（5.1） |

PM0214 这个编号，RM0090 的前言里就列在 Related documents 中。三本合起来上千页，没有人会通读。所以先做一道题，练习"该翻哪本"：

> [!question] 先猜一猜
> 下面四个问题，各去哪一本手册找？
> ① PA0 这个引脚，最大允许灌入多少电流？
> ② 串口的波特率寄存器 `USART_BRR`，每一位是什么意思？
> ③ 内核里 PendSV 异常是干什么的？
> ④ 芯片的 Flash 一共分几个扇区，每个多大？

> [!success]- 揭晓
> ① 数据手册。电流这种电气参数不在参考手册里。
> ② 参考手册。凡是"这个外设怎么用、寄存器每一位什么意思"，都在这里。
> ③ 内核编程手册。PendSV 是 Cortex-M 内核自己的异常，不是 ST 加的外设。
> ④ 参考手册，第 3 章 Embedded flash memory interface 里有扇区表。
>
> 规律：问**芯片这个"零件"本身**（引脚、电气、封装），翻数据手册；问**外设怎么用**，翻参考手册；问**内核怎么干活**，翻编程手册。

### 第四步：用手册量一量

回到刚才的 RAM 问题，不猜，去量。打开参考手册 RM0090，在第 2 章 Memory and bus architecture 里搜索 `system SRAM`，你会看到类似"192 Kbytes of system SRAM"的描述。再去第 3 章搜 `Capacity`，能看到 Flash 容量最大 1 Mbyte。

> [!success]- 揭晓：先猜一猜的答案
> 选 B。整颗芯片的 RAM 一共 192 KB，由 SRAM1（112 KB）、SRAM2（16 KB）和 CCM（64 KB）几块拼成，最大的 Flash 是 1 MB。
> 16 GB 除以 192 KB，大约是 8.7 万倍。第 1 章里你随手开的数组，到这里要先算账了。

> [!example] 探针：在框图里找出小镇
> 打开数据手册里的 Block diagram（框图），用笔圈出：CPU、Flash、SRAM、总线、时钟、GPIO。再数一数框图里有几个 GPIO 端口（HAL 库源码注释里写的是 F40x 系列有 A 到 I），和你数的对不对得上。

## 刚才发生了什么

你把板子上的东西和手册里的东西一一对上了。现在把小镇的角色和真名放在一起：

| 小镇里的 | 真名 | 在 STM32F407 上 |
|---|---|---|
| 镇长 | CPU 内核 | Cortex-M4（带浮点单元）。内核由 ARM 公司设计，ST 买来用 |
| 档案馆 | Flash | 存程序和常量，断电不丢，最大 1 MB |
| 办公桌 | RAM（SRAM） | 存变量和栈，断电全丢，共 192 KB |
| 办事窗口 | 外设 | GPIO、定时器、串口、CAN……由 ST 设计，挂在内核旁边 |
| 马路 | 总线 | 把 CPU、存储、外设连起来 |
| 钟声 | 时钟 | 全镇的人踩着同一个节拍办事 |

这就是[[【原理】单片机内部结构|单片机]]：**一颗芯片里装下 CPU、存储和外设，靠总线和时钟连起来**。

和你的电脑比，有一处差别要现在就知道：**单片机上没有操作系统**。电脑上，操作系统是"接生员"，它把你的程序从硬盘搬进内存再运行。单片机上没有这个角色：你的程序被烧录进 Flash，上电之后，CPU 直接从 Flash 里取指令执行，一条一条往下走。所以一个单片机程序，等于一段启动代码加上你写的 `main`，别无其他。

还有一个预告。Flash、RAM、外设，在 CPU 看来**住在同一张地址表上**：Flash 从 `0x0800 0000` 开始，SRAM 从 `0x2000 0000` 开始，外设从 `0x4000 0000` 开始（这几个数都在 RM0090 里核对过）。为什么这能让"往某个地址写一个数"点亮一盏灯，2.3 之后会说，想先看的人点 [[【原理】寄存器与内存映射|寄存器与内存映射]]。

再留意"办事窗口"那一行：一颗芯片上有好几个串口，有好几个定时器，GPIO 也分成 A 到 I 好几组端口。它们不是各不相同的怪东西，而是**同一种东西的多个实例**：每个串口都有自己的配置、自己的收发状态，也都支持同样的一套操作。这正是"对象"的样子：同一个类型，多个实例，各管各的状态。所以 HAL 库里的 `UART_HandleTypeDef`、`TIM_HandleTypeDef` 这类类型，是把芯片上本来就存在的这个事实，直接写成了 C 的 `struct`。比如本教程作者的一个工程里，就同时用着 `huart1`、`huart3`、`huart6` 三个串口对象。这件事 1.6 已经讲过，2.4 会回头用 HAL 的代码再看一次，想先看全貌的人点 [[【原理】C语言里的面向对象|C 语言里的面向对象]]。

回到开头那个问题。引脚最多能带多大电流，现在你知道去数据手册的 Electrical characteristics 一节找，不会再在参考手册里翻一个小时了。

## 记住这几条

1. **先问"我要的是哪一类信息"，再选手册。** 零件的事翻数据手册，外设怎么用翻参考手册，内核的事翻编程手册。
2. **型号的后缀决定 Flash 容量、引脚数和封装。** 动手之前，先确认你手上的那一颗到底是哪个后缀。
3. **Flash 存程序，断电不丢；RAM 存变量，断电清空。** 大数组、大缓冲区先算账，F407 的 RAM 一共才 192 KB。
4. **单片机上没有操作系统。** 程序存在 Flash 里，上电后 CPU 直接开始执行。
5. **手册说能、实测不行时，先查勘误表（Errata）。** 它是 ST 官方列出的"已知的坑"。
6. **不要通读手册，要会查。** 会查比会背重要。

## 练习

1. 抄下你板子芯片的完整丝印，按第二步的表拆开，再到数据手册的 Ordering information 里逐段核对。（复现）
2. 把型号改成 `STM32F407VGT6`，预测哪几段含义会变，哪几段不变。（改造）
3. 一个 `uint32_t buf[1000]` 占 RAM 的百分之几？如果是 `uint32_t buf[100000]` 呢？（预测）

> [!success]- 提示与答案方向
> 1. 以你的数据手册为准。如果某段对不上，说明我表里"待核对"的段需要你来纠正，欢迎。
> 2. 变的是引脚数和封装那两段（引脚数从 176 变成 100 左右，封装从 BGA 变成 LQFP，具体以数据手册为准，待核对）；Flash 那一段 `G` 不变，所以容量一样。引脚少了，能引出的 GPIO 也少了。
> 3. 4000 字节除以 192 KB（196,608 字节），约 2%。100000 个是 400,000 字节，已经超过整颗芯片的 RAM，链接会失败。

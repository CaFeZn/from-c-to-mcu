# 第 1 章 从第一句输出，到能处理命令的小程序

> 回到 [[00_教程导览]] ｜ 下一章：[[第2章_认识单片机]]
> 本章在电脑上完成，使用 VS Code + CMake + gcc，还不用接单片机。

第一次学 C，从 1.0 开始就行。先让程序运行，再让它输出你的话、记住数字、做出判断。代码重复了再引入函数，要管多个实例时再引入对象，文件变多时再展开工程组织。

工具会在需要时介绍到够用；想知道编译和链接内部怎样工作，再看 [[第0章_工具与构建_自学选读]]，不需要先补完原理再回来。

## 按自己的进度往下走

- **第一次写程序**：1.0 直接跟着操作，没有开场测验；接着读 1.1、1.2。
- **已经学过部分内容**：展开对应小节的跳读自测，确认相关操作和约定都会，再跳过。
- **程序能运行，但编辑器补全和跳转不对**：先看 1.0 的配置检查；需要 clangd 时再读 [[【拓展】让VSCode看懂CMake工程]]。
- **想了解多文件工程**：1.8 接着前面的命令表做，不要求先读第 0 章。
